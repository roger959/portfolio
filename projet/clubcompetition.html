🏆 Club et Competition - Projet de groupe

📜 Description du projet

Club et Competition est un projet realise en equipe dans le cadre de ma formation. L'objectif etait de concevoir une plateforme complete pour aider un club a organiser ses competitions et a centraliser ses informations.

Le projet propose une interface moderne permettant de consulter les competitions, de suivre les actualites du club et d'acceder aux informations principales depuis un espace clair et structure.

Image de la page d'accueil

🎯 Objectifs du projet

  • Centraliser les informations utiles du club sur une seule plateforme
  • Faciliter la consultation des competitions et de leur suivi
  • Proposer une interface simple a utiliser pour les membres
  • Structurer les donnees de maniere fiable pour le long terme

🧱 Stack technique

  • Frontend : HTML, CSS, JavaScript
  • Backend : PHP / Symfony
  • Base de donnees : MySQL
  • Outils : GitHub, VS Code, Trello
