🏆 Projet Club et Competitions

📜 Description du projet

Club et Competitions est une application de gestion de club sportif. Le projet centralise les operations principales : gestion des competitions, suivi des membres, actualites, commentaires et notifications.

L'objectif est de proposer une solution unique accessible sur web et mobile, avec une API centralisee pour garantir la coherence des donnees.

🏗️ Architecture

  • api-symfony/ : backend principal en Symfony (API REST)
  • react-web/ : front web avec React et Vite
  • react-mobile/ : front mobile avec React Native et Expo
  • database-project/ : scripts SQL (club_bdd.sql)
  • API-backend/ : ancien backend conserve pour compatibilite

🧱 Stack technique

  • Backend : PHP 8.2+, Symfony, Doctrine, MySQL
  • Web : React 19, Vite
  • Mobile : React Native, Expo SDK 54

⚙️ Fonctionnalites principales

  • Gestion des competitions et des participants
  • Gestion des roles : admin, organisateur, membre
  • Publication d'actualites et commentaires
  • Notifications liees aux actions importantes
  • Acces multi-plateforme : web et mobile

🛠️ Competences developpees

  • Concevoir et developper une API REST complete
  • Structurer et manipuler une base de donnees relationnelle
  • Synchroniser un backend avec deux clients (web et mobile)
  • Travailler en mode projet sur une architecture multi-dossiers
  • Mettre en place des controles d'acces selon les roles

🎓 Conclusion

Ce projet m'a permis de consolider mes competences en architecture applicative, en developpement full-stack et en organisation de projet. Il illustre une approche complete, de la base de donnees jusqu'aux interfaces web et mobile.
